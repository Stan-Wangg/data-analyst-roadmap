# Stage 5: Intermediate Power BI

**Back to Power BI, one level up.** This is where dashboards start to look like real work.

## Intermediate Power BI, in order

1. Relationships between tables
2. Basic DAX measures (SUM, AVERAGE)
3. Drill-through
4. Publish to Power BI Service

Step 4 needs a work or school email. Don't have one? Skip it. Share a screenshot or a PDF of your dashboard instead.
