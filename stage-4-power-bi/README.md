# Stage 4: Power BI

**Power BI turns your data into a dashboard a manager can read in 30 seconds.** Almost every data analyst job description ticks the Power BI box.

## The 4 stages to master Power BI

1. Load and clean your data
2. Model relationships
3. Write basic DAX measures
4. Build one clean dashboard

## Free teachers

- [How to Power BI](https://www.youtube.com/@HowtoPowerBI)
- [Curbal](https://www.youtube.com/@CurbalEN)

## Free tools

[Power BI Desktop](https://apps.microsoft.com/detail/9ntxr16hnw1t) is free on Windows.

On a Mac? Power BI Desktop doesn't run on macOS. Use a Windows machine, or build your Stage 5 dashboard in Excel or Google Sheets first. Project 01 is built for that.

Start tonight: load one [Kaggle dataset](https://www.kaggle.com/datasets), build one chart.
