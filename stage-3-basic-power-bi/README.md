# Stage 3: Basic Power BI

**Power BI turns your data into a dashboard a manager can read in 30 seconds.** Almost every data analyst job description ticks the Power BI box.

## Basic Power BI, in order

1. Load your data
2. Build your first chart
3. Add filters and slicers

That's enough to build a first dashboard. Relationships, DAX and publishing come in [Stage 5](../stage-5-intermediate-power-bi/).

## Free teachers

- [How to Power BI](https://www.youtube.com/@HowtoPowerBI)
- [Curbal](https://www.youtube.com/@CurbalEN)

## Free tools

[Power BI Desktop](https://apps.microsoft.com/detail/9ntxr16hnw1t) is free on Windows.

On a Mac? Power BI Desktop doesn't run on macOS. Use a Windows machine, or build your first dashboards in Excel or Google Sheets while you sort that out.

Start tonight: load one [Kaggle dataset](https://www.kaggle.com/datasets), build one chart. Your first dashboard won't be good. Keep practising and it will get better.
