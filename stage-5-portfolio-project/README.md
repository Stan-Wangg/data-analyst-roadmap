# Stage 5: One portfolio project

**Skills don't get interviews. Proof does.**

"I watched the tutorials" is not proof. One finished project that looks like real analyst work is.

You don't need ten projects. You need one you can explain without looking at the screen.

## Your project

**[Project 01: The Messy Sales Report](../project-01-messy-sales-report/)**

A realistic messy sales export. You clean it with a paper trail, find which regions and products are slipping, and build a one-page dashboard.

## How to make it yours

1. **Fork this repo** (top right of the page on GitHub).
2. Do the project.
3. Add your finished `.xlsx` file and fill in [`write-up-template.md`](../project-01-messy-sales-report/write-up-template.md) in your fork.
4. Put the link to your fork on your CV and LinkedIn.

Finished? Post it on Threads and tag [@stanleywangg](https://www.threads.com/@stanleywangg).

You're employable by Stage 5.
