# Stage 4: Intermediate SQL

**Back to SQL, one level up.** Now that you've seen data in a dashboard, the harder SQL questions make more sense.

## Intermediate SQL, in order

1. CASE WHEN
2. Subqueries
3. CTEs (the `WITH` clause)
4. Window functions

Master each one before moving on.
